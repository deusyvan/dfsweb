# Luiz Spinola Imóveis

Landing page premium para apresentação de 3 imóveis a investidores.

## Rodando localmente

```bash
npm install
npm run dev
```

Acesse: http://localhost:3000

## Deploy na Vercel

```bash
npx vercel --prod
```

Na primeira vez: escolha **Continue with GitHub** e siga o fluxo. O site estará online em menos de 2 minutos.
